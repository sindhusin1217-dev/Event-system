# 🎓 College Event Registration System

A web-based **College Event Registration System** developed using **Python Flask, HTML, CSS, JavaScript, and CSV**. The system allows students to register for college events and provides an admin panel to manage registrations efficiently.

## 📌 Project Overview

The College Event Registration System is designed to make the event registration process simple and organized. Students can register for different college events by providing their details. Administrators can securely log in and manage registration records.

## ✨ Features

- 📝 Student event registration
- 🔐 Admin login
- 📋 View all registrations
- 🔍 Search registrations
- ✏️ Edit registration details
- 🗑️ Delete registrations
- 📊 Event-wise registration reports
- 📧 Email validation
- 📱 10-digit phone number validation
- 🚫 Duplicate registration prevention
- 💾 CSV-based data storage
- 📱 Responsive user interface

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database/Storage:** CSV
- **Development Tool:** Visual Studio Code
